# Customer 360 — phân tích bán lẻ thiết bị điện tử

Phân tích khách hàng, doanh thu và dịch vụ từ dữ liệu giả lập năm 2025 bằng SQL Server, Python và Power BI.

- 600 khách hàng, 575 khách mua và 2.998 đơn hoàn tất; doanh thu 53,36 tỷ đồng.
- SQL xây dựng hồ sơ khách hàng, phân khúc và phân tích chi nhánh, kênh bán, sản phẩm, dịch vụ.
- Dashboard Power BI gồm 5 trang, có phân tích cohort và hành động.

[Bài phân tích trên Notion](https://app.notion.com/p/Customer-360-cho-chu-i-b-n-l-thi-t-b-i-n-t-3ad24d1b4aa180d9af83cefd8785196c) · [Truy vấn SQL](customer360.sql)

Tải và giải nén `customer-360.zip` để xem file PBIX, mã nguồn PBIP, dữ liệu giả lập và kết quả. Mở `Customer360_PowerBI_Final/Customer360_Final.pbix` bằng Power BI Desktop. Xem README trong thư mục đó trước khi refresh.

Dữ liệu chỉ gồm một năm và không có nhóm đối chứng; kết quả không chứng minh tính mùa vụ hay hiệu quả chiến dịch.
